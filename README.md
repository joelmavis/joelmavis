# 咖喱辣椒Joe

欧洲研究背景的 AI 产品与 GTM 从业者。从欧洲出发，观察 AI、技术主权与全球权力；也从产品、GTM 与组织采用的实践中理解技术如何进入真实工作。

## 研究方向

- AI 治理
- 技术主权
- 欧洲科技政治
- 中美欧技术关系
- AI 与全球权力

## 论文研究主题

> AI 商业化的关键，不只在于更好的模型或 Demo，而在于产品如何在真实工作中获得组织采用。

我关注模型能力、产品设计、组织流程与采用条件之间的关系：为什么有些 AI 产品能够进入真实工作，而另一些只能停留在演示层面。

## 公开研究基础设施

我正在建设开放的 [AI Governance Research Toolkit](https://github.com/joelmavis/ai-governance-research-toolkit)，沉淀可复用的研究方法、知识工具与智能体技能。

其中包括材料学习、情报观察、专题研究、公共表达与事实核查等工作流；工具以中文说明，面向任何需要进行证据导向研究与表达的使用者。
